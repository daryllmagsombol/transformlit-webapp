2. **`readJson` was dead code** in `build-pwa-assets.mjs` (never called). Removed (Sonar S1481/S1128 spirit; global AGENTS "no unused").
3. **`ORIGIN` was an unused const** in `build-pwa-assets.spec.ts`. Removed.
4. **Worker message used `event.data || {}`** instead of optional chaining; changed to `event.data ?? {}` per AGENTS.md S6690/S6606 preference.
5. **Update prompt live region wrapped the buttons.** `role="status"` + `aria-live` was on the container that also held the action buttons, so a status update could re-announce controls. Moved the live region to the announcement text only; the section keeps its `aria-label`.
6. **Hardened `pwa-worker.spec.ts`:**
   - Header assertion pinned `no-cache`, but the harness HTTPS proxy forcibly rewrites every response to `cache-control: no-store`, so the assertion would be dishonest in the harness. Changed to assert `no-store` (true in both production and harness) and documented why.
   - Added the R1 authenticated-navigation cache inspection (login via fixture, visit `/feed`, assert no `/api/`, `/auth/`, `/graphql`, `/_next/data/` entries), guarded to `testInfo.skip` when fixtures are absent so it never fabricates a pass.
7. **Added a same-build asset-only A→B identity test** to `build-pwa-assets.spec.ts` (same `buildId`, different font set ⇒ different `inventoryDigest`/`releaseId`/worker bytes). This is the exact guarantee Task 14A depends on.
